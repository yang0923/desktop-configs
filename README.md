# Desktop Configs

个人桌面与开发环境配置集合。

本仓库作为所有配置仓库的统一入口，通过 Git 子模块聚合各个独立项目，方便集中查看、管理和维护。每个配置项目都有自己的 Git 仓库，可以独立开发、更新和版本控制。


## 配置理念

- **模块化**：每个软件的配置独立管理，保持清晰的项目边界。
- **风格统一**：让桌面、窗口管理和开发环境保持一致的视觉与操作体验。
- **键盘优先**：减少对鼠标的依赖，追求高效、连贯的键盘操作。
- **易于维护**：利用 Git 记录修改历史，方便比较、备份和恢复配置。
- **便于扩展**：可以随时加入新的桌面工具或开发环境配置。

## 获取仓库

克隆本仓库及其所有子模块：

```bash
git clone --recurse-submodules https://github.com/yang0923/desktop-configs.git
cd desktop-configs
```

如果已经克隆本仓库，但尚未初始化子模块，可以执行：

```bash
git submodule update --init --recursive
```

## 更新配置

每个子模块都有独立的 Git 仓库。修改配置后，应先在对应的子仓库中提交并推送更改。

如果希望本仓库使用某个子模块的最新提交，需要在本仓库中更新对应的子模块引用，并提交这一变更。

同步本仓库记录的子模块版本：

```bash
git submodule update --init --recursive
```

## 仓库说明

本仓库主要用于聚合和索引各个配置项目，不重复维护每个软件的具体配置。各项目的详细说明、安装方法和个性化设置，以对应子仓库中的文档为准。
